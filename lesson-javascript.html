JavaScript พื้นฐาน

ภาษาที่ทำให้เว็บไซต์ของคุณมีชีวิตชีวา

1. JavaScript คืออะไร?

JavaScript (มักเรียกสั้นๆ ว่า JS) เป็นภาษาสคริปต์ที่ใช้สร้างความ Interactive ให้กับเว็บไซต์ เช่น การกดปุ่มแล้วมีป๊อปอัปเด้งขึ้นมา การตรวจสอบฟอร์ม หรือการดึงข้อมูลมาแสดงแบบไม่ต้องโหลดหน้าใหม่

2. ตัวอย่างโค้ดแรกของคุณ

ลองเขียนโค้ดนี้ใน Playground ของเรา:

// นี่คือคอมเมนต์
console.log("Hello, World!");
alert("ยินดีต้อนรับสู่ Dev-Mate");

3. การประกาศตัวแปร

ใน JavaScript เราใช้ `let` หรือ `const` ในการประกาศตัวแปร

let name = "Mate";
const age = 25;
console.log(name + " อายุ " + age + " ปี");
