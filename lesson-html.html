บทเรียน: HTML พื้นฐาน

เริ่มต้นสร้างโครงสร้างเว็บไซต์แรกของคุณ

1. HTML คืออะไร?

HTML (HyperText Markup Language) ไม่ใช่ภาษาโปรแกรมมิ่ง แต่เป็นภาษาที่ใช้ "ติดป้าย" (Markup) ข้อความหรือรูปภาพ เพื่อบอกเบราว์เซอร์ว่า "ส่วนนี้คือหัวข้อ", "ส่วนนี้คือย่อหน้า", "ส่วนนี้คือรูปภาพ"

ลองนึกภาพว่า HTML คือโครงกระดูกของมนุษย์ ส่วน CSS คือผิวหนังและเสื้อผ้า และ JavaScript คือสมองที่ทำให้เราขยับได้ครับ

2. โครงสร้างของไฟล์ HTML

ทุกไฟล์ HTML จะต้องมีโครงสร้างพื้นฐานแบบนี้เสมอ:

<!DOCTYPE html>
<html>
<head>
    <title>ชื่อเว็บของฉัน</title>
</head>
<body>
    <!-- เนื้อหาที่จะแสดงบนหน้าจอ -->
    <h1>สวัสดีชาวโลก</h1>
</body>
</html>
  • <!DOCTYPE html>: บอกเบราว์เซอร์ว่านี่คือไฟล์ HTML5
  • <head>: ส่วนเก็บข้อมูลเบื้องหลัง (เช่น ชื่อเว็บ, ภาษาที่ใช้) จะไม่แสดงบนหน้าจอ
  • <body>: ส่วนที่จะแสดงผลให้ผู้ใช้เห็นทั้งหมด

3. แท็ก (Tags) และ องค์ประกอบ (Elements)

HTML ใช้เครื่องหมาย < และ > ในการสร้างแท็ก โดยทั่วไปจะมีแท็กเปิดและแท็กปิด เช่น:

<h1>นี่คือหัวข้อใหญ่</h1>
<p>นี่คือย่อหน้าข้อความ</p>

หัวข้อ (Heading) มีตั้งแต่ <h1> ถึง <h6> โดย h1 ตัวใหญ่สุด และ h6 ตัวเล็กสุด
