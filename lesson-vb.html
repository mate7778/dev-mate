ภาษา VB.NET พื้นฐาน

ภาษาที่อ่านง่ายที่สุด คล้ายภาษาอังกฤษ และเป็นดาวเด่นบนแพลตฟอร์ม Windows

1. VB.NET คืออะไร?

VB.NET (Visual Basic .NET) เป็นภาษาที่พัฒนาโดย Microsoft ต่อยอดมาจากภาษา Visual Basic เดิม จุดเด่นที่สุดของมันคือ Syntax ที่อ่านง่ายมาก ใครที่เคยเขียนภาษาสคริปต์อื่นๆ อย่าง Python หรือ JavaScript มาบ้าง จะพบว่า VB อ่านเข้าใจง่ายไม่แพ้กันเลยครับ

2. โครงสร้างโปรแกรมแรก (Hello World)

ใน VB.NET เรามักจะใช้ฟังก์ชัน Console.WriteLine ในการแสดงผลข้อความออกทางหน้าจอ

Module Program
    Sub Main()
        ' พิมพ์ข้อความออกหน้าจอ
        Console.WriteLine("Hello, World!")
    End Sub
End Module

3. ตัวแปร (Variables)

VB.NET มีการประกาศตัวแปรที่ชัดเจน เราใช้คำว่า Dim (Dimension) ในการสร้างตัวแปร

Dim name As String = "Mate"
Dim age As Integer = 25

Console.WriteLine("สวัสดี " & name)
Console.WriteLine("อายุ: " & age)

* สังเกตว่า VB ใช้เครื่องหมาย & ในการเชื่อมข้อความ (String Concatenation) แทนเครื่องหมาย + หรือ . ในภาษาอื่นๆ ครับ

4. เงื่อนไข (If-Else)

การเขียนเงื่อนไขใน VB จะปิดท้ายด้วย End If เสมอ ทำให้อ่านง่ายและไม่สับสน

Dim score As Integer = 85

If score >= 80 Then
    Console.WriteLine("ยอดเยี่ยม")
ElseIf score >= 50 Then
    Console.WriteLine("ผ่าน")
Else
    Console.WriteLine("ต้องปรับปรุง")
End If

5. ลูป (For Loop)

การวนซ้ำใน VB จะใช้คำว่า For ... Next

For i As Integer = 1 To 5
    Console.WriteLine("รอบที่ " & i)
Next
