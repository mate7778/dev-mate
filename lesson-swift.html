ภาษา Swift พื้นฐาน

ภาษาสุดล้ำสำหรับการสร้างแอปพลิเคชันบน iPhone และ Mac

1. Swift คืออะไร?

Swift ถูกเปิดตัวโดย Apple ในปี 2014 เพื่อแทนที่ภาษา Objective-C เดิม มีจุดเด่นที่โค้ดอ่านง่าย ปลอดภัยสูง (Safe) และรวดเร็ว นิยมใช้ทำแอป iOS, macOS, watchOS และ tvOS

2. โปรแกรมแรกของคุณ

Swift ไม่บังคับให้มีฟังก์ชัน main ถ้าเขียนเป็น Script ทั่วไป

import Foundation

// พิมพ์ข้อความ
print("Hello, World!")

3. ตัวแปรและค่าคงที่

Swift แยกชัดเจนระหว่าง `var` (แก้ไขค่าได้) และ `let` (ค่าคงที่ ห้ามแก้)

var age = 25     // เปลี่ยนค่าได้
let name = "Mate" // เปลี่ยนค่าไม่ได้

// การแทรกตัวแปรในข้อความ (String Interpolation)
print("สวัสดี \(name) อายุ \(age) ปี")

4. Optionals (จุดเด่นของ Swift)

Swift บังคับให้เราจัดการค่า Null (nil) อย่างปลอดภัยด้วย Optionals (?)

var middleName: String? = nil // อาจจะมีหรือไม่มีค่าก็ได้

if let safeName = middleName {
    print("ชื่อกลางคือ \(safeName)")
} else {
    print("ไม่มีชื่อกลาง")
}

* ภาษา Swift ต้องเขียนบนโปรแกรม Xcode ซึ่งใช้งานได้เฉพาะบน macOS เท่านั้น
