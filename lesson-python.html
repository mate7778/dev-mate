บทเรียน: Python พื้นฐาน

ภาษาโปรแกรมมิ่งที่อ่านง่ายที่สุดในโลก

1. ทำความรู้จักกับ Python

Python เป็นภาษาโปรแกรมมิ่งที่ได้รับความนิยมสูงมากในปัจจุบัน จุดเด่นคือโค้ดอ่านง่ายเหมือนภาษาอังกฤษ และไม่ต้องพิมพ์เครื่องหมายปีกกา { } ให้วุ่นวายใจ

2. การแสดงผล (Print)

ฟังก์ชันพื้นฐานที่สุดคือ print() ใช้สำหรับแสดงข้อความหรือตัวเลขออกทางหน้าจอ

print("สวัสดีครับ!")
print("ยินดีต้อนรับสู่ Python")
print(10 + 5)

ผลลัพธ์ที่ได้:
สวัสดีครับ!
ยินดีต้อนรับสู่ Python
15

3. ตัวแปร (Variables)

ตัวแปรคือกล่องสำหรับเก็บข้อมูล เราสามารถสร้างตัวแปรและนำไปใช้ทีหลังได้เลย โดยไม่ต้องระบุชนิดข้อมูล

name = "Mate"
age = 25

print("สวัสดี " + name)
print("คุณอายุ", age, "ปี")

4. การรับค่าจากผู้ใช้ (Input)

เราสามารถให้โปรแกรมถามข้อมูลจากผู้ใช้ได้ด้วยฟังก์ชัน input()

user_name = input("กรุณากรอกชื่อของคุณ: ")
print("สวัสดีคุณ " + user_name)
