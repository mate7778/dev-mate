ภาษา Go (Golang) พื้นฐาน

ภาษาสายสปีดจาก Google ที่ครองใจสาย Cloud และ Microservices

1. Go คืออะไร?

Go (หรือ Golang) ถูกสร้างโดย Google เพื่อแก้ปัญหาเรื่องความซับซ้อนของภาษา C++ และ Java จุดเด่นคือมีโครงสร้างที่เรียบง่าย คอมไพล์เร็วมาก และมีระบบจัดการ Concurrency (การทำงานหลายอย่างพร้อมกัน) ที่ยอดเยี่ยม นิยมใช้ทำ API, ระบบ Cloud (เช่น Docker, Kubernetes เขียนด้วย Go)

2. โครงสร้างโปรแกรมแรก

package main

import "fmt"

func main() {
    // พิมพ์ข้อความ
    fmt.Println("Hello, World!")
}

3. ตัวแปรและการประกาศ

Go มีวิธีประกาศตัวแปรได้หลายแบบ และมี Type Inference (เดาชนิดข้อมูลให้)

var name string = "Mate"
age := 25 // ใช้ := ในการประกาศและกำหนดค่าพร้อมกัน (เดาชนิดเป็น int)

fmt.Println("สวัสดี", name)
fmt.Printf("อายุ: %d ปี\n", age)

4. การทำงานซ้ำ (For Loop)

ในภาษา Go ไม่มี While Loop ใช้แค่ `for` เท่านั้น

// ลูปแบบปกติ
for i := 1; i <= 3; i++ {
    fmt.Println("รอบที่", i)
}

// ลูปแบบนับไม่ถ้วน (คล้าย While)
count := 0
for count < 3 {
    fmt.Println("นับ:", count)
    count++
}

* ภาษา Go ต้องติดตั้ง Go Compiler (สามารถดาวน์โหลดได้ฟรีที่ go.dev)
