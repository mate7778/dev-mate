ภาษา Java พื้นฐาน

ราชาแห่งภาษา Enterprise ที่ทรงพลังและรองรับการทำงานขนาดใหญ่

1. Java คืออะไร?

Java เป็นภาษาโปรแกรมมิ่งแบบ Object-Oriented (OOP) ที่ได้รับความนิยมสูงสุดในกลุ่มองค์กรธนาคารและระบบขนาดใหญ่ รวมถึงเป็นภาษาหลักในการเขียนแอปพลิเคชัน Android จุดเด่นของ Java คือ "เขียนครั้งเดียว รันได้ทุกที่" (Write Once, Run Anywhere)

2. โครงสร้างโปรแกรมแรก (Hello World)

ภาษา Java บังคับให้ทุกโค้ดต้องอยู่ใน Class และมี Method main เป็นจุดเริ่มต้นเสมอ

public class Main {
    public static void main(String[] args) {
        // พิมพ์ข้อความออกทางหน้าจอ
        System.out.println("Hello, World!");
    }
}

3. ตัวแปรและชนิดข้อมูล (Data Types)

Java เป็นภาษาแบบ Strongly-typed คือต้องระบุชนิดข้อมูลให้ชัดเจน

int age = 25;             // จำนวนเต็ม
double price = 99.99;     // ทศนิยม
String name = "Mate";     // ข้อความ (ใช้ String ตัวใหญ่)
boolean isActive = true;  // ค่าความจริง (true/false)

System.out.println("ชื่อ: " + name + ", อายุ: " + age);

4. เงื่อนไข (If-Else)

int score = 85;

if (score >= 80) {
    System.out.println("ยอดเยี่ยม");
} else if (score >= 50) {
    System.out.println("ผ่าน");
} else {
    System.out.println("ต้องปรับปรุง");
}

* ภาษา Java ไม่สามารถรันบนเบราว์เซอร์ได้โดยตรง ต้องติดตั้ง JDK บนเครื่องของคุณ
