หลักสูตร HTML & CSS

เริ่มต้นสร้างหน้าเว็บตั้งแต่องค์ประกอบแรก จนถึงการจัดหน้าตาให้สวยงาม

  • โครงสร้างหน้าเว็บ (HTML Skeleton)
  • การใช้งาน Text & Headings
  • การแทรกลิงก์และรูปภาพ

หลักสูตร Python พื้นฐาน

เรียนภาษาโปรแกรมมิ่งที่เข้าใจง่ายที่สุด เพื่อต่อยอดไปสู่ Data, AI หรือ Backend

  • ตัวแปรและชนิดข้อมูล
  • การรับค่าและแสดงผล
  • เงื่อนไข (If/Else) และลูป (Loops)

JavaScript & ภาษาอื่นๆ

  • JavaScript พื้นฐาน
  • ภาษา Java, C++, C#
  • Swift และ Go (Golang)
