ภาษา C++ พื้นฐาน

สุดยอดภาษาสายประสิทธิภาพสูง สำหรับงานที่ต้องการความเร็วเป็นเลิศ

1. C++ คืออะไร?

C++ เป็นภาษาที่ต่อยอดมาจากภาษา C มีความเร็วในการประมวลผลสูงมาก นิยมใช้พัฒนาเกม (Game Engine ระดับโลหะอย่าง Unreal Engine), ระบบปฏิบัติการ, และโปรแกรมที่ต้องการจัดการหน่วยความจำอย่างละเอียด

2. โครงสร้างโปรแกรมแรก

เราต้องนำเข้า Library iostream เพื่อใช้ในการรับส่งข้อมูล

#include <iostream>
using namespace std;

int main() {
    // พิมพ์ข้อความและขึ้นบรรทัดใหม่
    cout << "Hello, World!" << endl;
    return 0; // บอกว่าโปรแกรมทำงานจบแบบไม่มีข้อผิดพลาด
}

3. ตัวแปรและการรับค่าจากคีย์บอร์ด

#include <iostream>
using namespace std;

int main() {
    int age;
    string name;
    
    cout << "กรุณากรอกชื่อ: ";
    cin >> name; // รับค่าจากคีย์บอร์ด
    
    cout << "สวัสดี " << name << endl;
    return 0;
}

4. ลูป (For Loop)

for (int i = 1; i <= 5; i++) {
    cout << "รอบที่ " << i << endl;
}

* ภาษา C++ ต้องใช้ Compiler (เช่น GCC, MinGW) ในการคอมไพล์โค้ดก่อนรัน
